# TripTales

TripTales is a modern travel storytelling platform where people can share emotional journeys, hidden places, peaceful stays, dreamy cafés, and unforgettable memories from around the world.

Built with a soft aesthetic and human-centered experience, TripTales focuses on meaningful travel instead of crowded tourist guides.

## Features

- Beautiful modern UI
- Email & Google Authentication
- Share travel memories and experiences
- Explore stories from travelers
- Responsive design
- Soft pastel aesthetic inspired interface

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB

### Authentication
- Firebase Authentication
